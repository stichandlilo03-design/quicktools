## MONETIZATION SETUP

### 1. Google AdSense
1. Sign up at adsense.google.com
2. Add site: www.quicktools.sbs
3. Paste verification script in <head>
4. Wait 1-14 days for approval
5. Replace every <!-- Ad --> comment with AdSense unit:
```html
<ins class="adsbygoogle"
     style="display:block"
     data-ad-client="ca-pub-XXXXXXX"
     data-ad-slot="XXXXXXX"
     data-ad-format="auto"
     data-full-width-responsive="true"></ins>
<script>(adsbygoogle = window.adsbygoogle || []).push({});</script>
```

### 2. Google Search Console
1. search.google.com/search-console
2. Add property → www.quicktools.sbs
3. Verify via DNS TXT record
4. Submit sitemap.xml
5. Request indexing of homepage

### 3. Bing Webmaster
1. bing.com/webmasters
2. Import from Google Search Console
3. Gets Bing + Yahoo traffic (+10-15%)
